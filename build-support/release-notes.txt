balmunlock 0.7.1 — TWRP in both slots for OTA

Enter both, then yes in the TWRP confirmation to install recovery_a and recovery_b
without changing the active slot. Available in menu options 2 and 3.
The current-slot default and explicit a/b selection remain available.

Both partition sizes are checked and both full originals are backed up and
verified before any flash. Differing partitions are written inactive first;
identical images are skipped. Both final SHA-256 values must match before success.
Each partition has its own backup, hash and progress in state.json. A partial
failure stops without automatically retrying or restoring either partition.

Both mode is covered by host tests with independent partitions and failure
injection; it was not separately hardware-tested. Single-slot a/b installation
was previously tested on A101BM. The Windows ZIP contains only the utility,
runtime dependencies, USB preset and bundled TWRP 20261031. Keep the sessions/
and recovery-sessions/ backup directories.

The existing stock and ADB-root unlock paths are unchanged from 0.7.0.
Unlocking erases user data; installing TWRP on an unlocked phone does not.
