balmunlock 0.5.2 — TWRP 20261025

The start menu provides unlock only, TWRP only, and unlock + TWRP.
Both A101BM and X01A are supported on stock Android 12 / 1.280, active slot b.

TWRP updates no longer require rebuilding balmunlock. Keep one .img with any
filename in recovery/, or use --recovery-image PATH. An image different from
the bundled build shows a warning within the normal installation confirmation.
Size and structure checks, original recovery backup, selected-image hash binding
and readback verification are retained. Runtime TWRP version/fingerprint are
recorded without requiring a particular build. Release packaging still verifies
the exact bundled image and archive hashes.

Update the bundled recovery to TWRP 3.7.1_12-BALMUDA_Phone (20261025).

- Clear explanation when metadata decryption fails, including the Format Data option.
- Clear message when a pending installation is skipped after PIN entry is cancelled.

The same image supports A101BM and X01A. Installation, backup verification,
the three-option menu and automatic RU/EN language selection are retained.

Retain the recovery-sessions/ and sessions/ backup directories.
