balmunlock 0.7.2 — handle ADB restarts during TWRP backup

Fixes an interrupted recovery backup when TWRP restarts ADB during USB/MTP
initialization. Read-only operations have bounded retries after rechecking
the same phone, active slot and TWRP root access. Partial copies must still
pass the full size and SHA-256 checks. Flash commands are never retried.

The both option installs TWRP in recovery_a and recovery_b without changing
the active slot. Both full originals are saved and verified before any flash.
Hardware-tested on A101BM running Android 17 with slot a active: the ADB
restart was handled, both partitions were flashed and both hashes verified.
354 host tests pass, including disconnect and partial-copy failure cases.

Available through menu options 2 and 3. Current-slot default and explicit a/b
selection remain available. The unlock paths are unchanged.
Unlocking erases user data; installing TWRP on an unlocked phone does not.

The Windows ZIP contains only the utility, runtime dependencies, USB preset
and bundled TWRP 20261031. Keep sessions/ and recovery-sessions/ backups.
