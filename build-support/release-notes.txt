balmunlock 0.5.1 — TWRP for A101BM and X01A

TWRP installation and unlock + TWRP now support both BALMUDA Phone models:
- A101BM: stock Android 12, 1.280PO.0686.a.
- X01A: stock Android 12, 1.280MI.0648.a.

The installer recognizes each model's own build and fingerprints, saves the
current recovery, flashes recovery_b and checks the result before returning
to Android. Use active slot b; TWRP installation requires an unlocked bootloader.
The combined workflow can unlock first. Existing unlock sessions remain compatible.

The three-option menu and automatic RU/EN language selection are retained.
The RU/EN guides now give the same installation path for both models.

The TWRP image is unchanged: 3.7.1_12-BALMUDA_Phone (20261024).
Image SHA-256:

Fixed TWRP ZIP SHA-256 (instructions updated for both models):

The Windows ZIP includes the image. A separate TWRP ZIP includes the image,
manual installation guide, changelog and SHA256SUMS. Both ZIPs have checksum
files. The existing v0.5.0 release and its fixed archive remain available.

Unlocking erases user data. Installing TWRP on an unlocked phone does not.
Retain the recovery-sessions/ and sessions/ backup directories.
